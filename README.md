# Robot Feedback — Frontend
---

## Running with Docker

Orchestrated from the backend repo. Clone both repos as siblings, then:

```bash
cd boa-robot-feedback-backend
docker compose up -d
```

---

## Running Standalone

```bash
npm install
npm run dev
```


## Tech Stack

- **Framework** — Next.js 14, TypeScript
- **Styling** — Tailwind CSS
- **State** — TanStack Query
